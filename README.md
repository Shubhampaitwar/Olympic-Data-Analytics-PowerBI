# 🏅 Olympic Data Analytics Using Power BI

## 📌 About the Project

I created this project using Power BI to analyze historical Olympic Games data and understand different trends related to athletes, countries, sports, events, and medals.

The main goal of this project was to explore Olympic data, create interactive dashboards, and find meaningful insights through data visualization.

## 🎯 Project Objectives

- Analyze Olympic medal trends over the years.
- Identify the top-performing countries and athletes.
- Analyze athlete participation by age and gender.
- Understand which sports have the highest participation and medal counts.
- Compare the performance of host and non-host countries.
- Explore historical Olympic data using interactive dashboards.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization
- Data Modeling

## 📂 Dataset

I worked with historical Olympic Games data containing information about:

- Athletes
- Countries
- Sports
- Events
- Medals
- Gender
- Age
- Olympic Year and Season

## 📊 Dashboard Pages

I created six interactive dashboard pages:

**1. Global Medal Overview**
- Total medals distributed.
- Gold, Silver, and Bronze medal analysis.
- Medal trends over the years.
- Top 10 countries by medals.
- Events held across different Olympic years.

**2. Country Insights**
- Athlete participation by country.
- Medal distribution.
- Sports-wise medal analysis.
- Country performance comparison.

**3. Athlete Spotlight**
- Top 10 athletes by total medals.
- Medal-winning vs. non-medal-winning athletes.
- Most participated athletes.
- Athlete age distribution.

**4. Sports & Event Analysis**
- Total events and Olympic Games.
- Top sports by medals.
- Country dominance in sports.
- Sport-wise athlete participation.
- Medal trends over time.

**5. Host Country Analysis**
- Host vs. non-host medal comparison.
- Total Olympics hosted by each country.
- Host-country medal trends.
- Events conducted by host countries.

**6. Gender & Demographics**
- Gender-wise medal distribution.
- Athlete participation by age group.
- Youngest and oldest medal winners.
- Male and female participation analysis.

## 🧹 Data Cleaning & Preparation

I used Power Query Editor to prepare the dataset for analysis.

Some of the tasks I performed:
- Removed duplicate records.
- Standardized data formats.
- Changed date columns from text format to date format.
- Prepared the data for visualization.

## 🔍 Key Insights

While analyzing the data, I observed the following:

- Around 21K medals were distributed across the Olympic Games.
- The United States ranked first with 3,009 medals.
- Approximately 156K athlete records were analyzed.
- Only 16.85% of athletes won medals.
- The 21–25 age group had the highest participation.
- Athletics recorded the highest athlete participation, with 47,792 athletes.
- Male athlete participation was higher than female participation in the dataset.
- Host countries recorded higher overall medal counts than non-host countries.
